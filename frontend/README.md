# AI FlowOps Frontend

React/Vite dashboard for the hackathon MVP.

## Run

```bash
npm install
npm run dev
```

Set API base URL if needed:

```env
VITE_API_BASE_URL=http://localhost:3001
```

## Demo Prompts

```text
Telegram sikayetlerini Discord destek kanalina gonder
Son 10 maili ozetle
Odeme tarihi yaklasan maili bul ve hatirlat
```

The UI shows the chat planner, approval card, active tasks, run logs, and AI test panel.
